MiniMax Code 章鱼开屏动画 · 补丁包
==================================

装上以后，从桌面或开始菜单打开 MiniMax Code，会先播一段 14 秒的章鱼娘开屏动画，
动画最后落到 MiniMax Code 的启动页，再无缝换成真正的软件窗口，接着就能直接用。

要求
----
- Windows 10 / 11，已经装好 MiniMax Code 桌面版（默认装在 %LOCALAPPDATA%\Programs\MiniMax Code）。
- 不需要联网，不需要管理员权限，不装任何服务。

安装
----
1. 把整个文件夹解压到一个以后不会删、不会挪的位置（比如 D:\Tools\MiniMaxCodeBoot）。
   快捷方式会指向这个文件夹，挪走了就打不开。
2. 双击「安装到快捷方式.cmd」。
   它会把桌面、开始菜单里指向 MiniMax Code 的快捷方式改成先播动画，名字和图标不变。
   每个被改的快捷方式都会先备份，备份和记录在文件夹里的 .integration 目录。
3. 之后照常点 MiniMax Code 的图标就行。

只想看一下效果、不改任何快捷方式：直接双击 MiniMaxCodeBoot.exe。

播放时
------
- Esc 或右上角「跳过」可以直接进入软件。
- 软件还没启动好时，动画会停在落版画面等它，底下会显示「MiniMax Code 正在启动…」。
- MiniMax Code 已经开着、缩在托盘里也没关系，动画会把它的窗口叫出来再交接。
- 交接时会把 MiniMax Code 的窗口调成和动画一样大（1920×1080），之后保持这个大小。
  屏幕比 1920×1080 小的话，把 launcher.json 里的 PlayerWidth / PlayerHeight 改成 1280 / 720。

卸载 / 还原
-----------
双击「恢复原快捷方式.cmd」，所有改过的快捷方式会换回原样（会先核对备份的校验值）。
还原以后再删掉这个文件夹即可。

任务栏上固定的图标是 Windows 自己缓存的，安装后如果点它还是直接进软件，
把它取消固定、再从开始菜单重新固定一次就好。

文件说明
--------
MiniMaxCodeBoot.exe     启动器（基于开源项目 Dragon Codex Boot 改写，MIT 许可）
launcher.json           配置：动画停顿点、交接时间、窗口大小
media\startup.mp4       开屏动画（1920×1080，60fps，含音乐和音效）
scripts\                改快捷方式 / 还原用的脚本
logs\launcher.log       运行记录，出问题时看这里

本补丁是社区作品，和 MiniMax 官方无隶属关系。
